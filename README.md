A project on loan approval prediction using machine learning. 
The dataset used was obtained from Kaggle.
The dataset can be accessed with this URL: https://www.kaggle.com/datasets/architsharma01/loan-approval-prediction-dataset
Seven supervised machine learning algorithms were built, explored and compared.
This project shows factors that can affect the approval of a loan request, the dataset parameters that were most useful in the machine learning models development and the outcome of these models.
